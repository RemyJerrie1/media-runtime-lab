# Caption font

`NotoSansTC.ttf` is the unmodified Noto Sans TC variable font from
[Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosanstc), downloaded on 2026-09-22.
Source filename: `NotoSansTC[wght].ttf`. The caption renderer selects weight 400.

- SHA-256: `864727d210d54f2537bbe23b3a839436c3992af72de9322af5270897246bd44f`
- Size: 11,941,968 bytes. The full font is intentionally bundled for offline Traditional Chinese coverage; it is requested only when the hamster preview mounts and is browser-cacheable.
- License: SIL Open Font License 1.1; see the accompanying `OFL-NotoSansTC.txt` for the original copyright and full terms.
- No CDN or installed system font is required. A failed font load prevents capture-ready and offers retry.
